## 双子玻璃塔楼优化与导入（2026-10-19）

源文件保留在 `/Users/channel1/Downloads/Meshy_AI_Twin_Glass_Towers_1019071338_texture.glb`。下表 MB 按 1,000,000 字节计算。

| 版本 | 三角面 | 顶点 | 文件大小 | PBR 贴图 |
| --- | ---: | ---: | ---: | --- |
| 原始 | 4,351,840 | 3,509,250 | 172.08 MB | 三张 2048×2048 JPEG |
| 轻量 | 118,670 | 105,201 | 1.75 MB | 三张 1024×1024 WebP |
| 近景 | 399,304 | 344,632 | 5.13 MB | 三张 2048×2048 WebP |

优化使用 glTF Transform 4.5.1、meshoptimizer 1.2.0 和 sharp 0.35.5。先合并相同顶点，再使用 `simplifyWithAttributes`，同时考虑法线（权重 0.5）与 UV（权重 2），开启 `Permissive` 和 `Prune`。轻量版目标 120,000 面、误差上限 0.015；近景版目标 400,000 面、误差上限 0.003。之后移除未引用数据、将贴图转换为质量 90 的 WebP，并使用 Meshopt high 压缩和顶点量化。保留原有不透明 PBR 材质、双面属性、颜色/法线/金属粗糙度贴图；运行时接入现有环境反射。

双子塔两档均位于 `(0, -48)`，绕 Y 轴旋转 180°，让低矮的退台裙房朝向前面的主楼；高度 50 米，宽约 75.1 米、深约 41.2 米，底面自动贴地。主楼位于 `(0, -114)`，在上次前移 17 米的基础上再向相机前移 6 米，高度仍为 33 米；两组建筑沿 Z 轴相隔约 18 米。间隔内的左右绿化庭院位于 X `[-55,-5]` / `[5,55]`、Z `[-85.5,-69.5]`，与道路贴图中的新增草坪一致。模型原始尺寸无实际米制标定，这里是展示比例。自动模式在距离 225 米内预加载精模，155 米内切入，离开 185 米后切回轻量版；右上角可手动选择精模/轻量。默认相机在 `(125, 115, -235)`，看向 `(0, 17, -85)`，对应参考图从右上向左下看的箭头方向。左下角提供“箭头视角 / 园区总览 / 查看双子塔”。默认入口为 `http://127.0.0.1:1231/?tab=campus`，双子塔近景入口保留 `&focus=twin-glass`。

主楼的两档模型共用一张 2048×2048 无损 WebP 遮罩，由 `scripts/build-campus-glass-mask.py` 从原始颜色贴图中的青蓝幕墙区域生成。R 通道控制清漆层，G 通道控制粗糙度，B 通道控制金属度。运行时使用 `MeshPhysicalMaterial`、IOR 1.5、清漆粗糙度 0.08 和环境反射，让玻璃区域有反射，同时保留白色楼板的哑光效果。原始颜色及法线贴图继续使用。中心建筑材质滑块仍可调整，旧版材质参数首次加载时迁移到新的玻璃默认值，其余光影设置保留。

已通过项目构建、TypeScript 检查、两档模型解码和浏览器画面检查。预览图保存在 `assets/campus/twin-glass-towers-campus-preview.jpg` 与 `assets/campus/twin-glass-towers-detail-preview.jpg`。轻量版适合园区远景，近看请使用精模；原始 AI 模型的窗格和边缘起伏仍会保留。

## 道路车辆（2026-10-19）

源文件为 Downloads 中的 `Meshy_AI_Golden_Horizon_SUV_1019083424_texture.glb` 和 `Meshy_AI_Midnight_Glide_1019090631_texture.glb`。使用 glTF Transform 4.5.1 进行顶点合并、Meshopt 压缩和 1024×1024 WebP 贴图压缩，不进行减面；两者保留 9,385 / 10,118 个三角面，文件由 6.52 / 5.61 MB 缩到 343 / 242 KB。原始车头均朝 -X，加载时统一到 +Z 前向并按车长适配，车轮底部贴在路面上。

当前有两辆 SUV 和一辆轿车，最多三辆同时出现。车辆通过两条纵向道路的南北入口进出，有四条直行路线和两条经过中间横路转弯的路线。各次行程从地图一端进入，在另一端驶出后隐藏，分别等待约 8–25 秒再从不同入口开始新行程。首轮出场时间为 0、4.8、12.6 秒，后续任意两次出场至少相隔 2.5 秒；入口被占用时继续等待。

三辆车基础速度分别为 5.8、7.1、8.6 米/秒（约 21、26、31 km/h），每次行程再随机浮动 ±10%，转弯会减速，同向接近前车时会跟随减速。路线按道路贴图中的轻微弯曲适配，车道距道路中心 3.3 米，车头跟随路径切线。车辆到达终点后不会立即跳回起点，后台长帧也会限制单次推进时间。

实现位于 `src/campus/traffic.ts`、`trafficRoutes.ts` 与 `trafficSimulation.ts`，车型只加载一次并共享网格和材质。左下角“查看车辆”进入跟车视角，“箭头视角 / 园区总览 / 查看双子塔”退出跟车。跟车入口为 `http://127.0.0.1:1231/?tab=campus&focus=traffic`。状态栏显示当前正在地图内行驶的车辆数量。

`scripts/check-campus-traffic.mjs` 检查六条穿行路线的入口/出口、4.9×2.15 米车身沿途仍在沥青路面内、不同出场时间和速度、消失后更换入口返回，以及五分钟模拟中持续错开的多次出场。使用 Node 24 运行 `node --experimental-strip-types --test packages/examples/scripts/check-campus-traffic.mjs`。同时通过 TypeScript、示例构建及浏览器行驶预览检查。

## 交给「生图 AI」的总提示词

## Meshy 生成与交付约束

- 使用**单资产参考图**进入 Image-to-3D；不要把最初的整张鸟瞰效果图直接喂给 Meshy，否则它会把道路、树木和其它楼糊成一个巨型网格。
- 优先生成带 PBR 贴图的 GLB。检查背面、屋顶、底面、法线与窗格；前后左右都应可用。发现建筑像薄片时，先修改参考图的角度或增加侧视图，再重新生成。
- 图 A 目标 ≤ 120k 三角面、贴图 ≤ 2K；图 B ≤ 30k 三角面、贴图 ≤ 1K；图 C ≤ 10k 三角面。尽量一资产一材质、少量纹理，避免透明玻璃和细碎几何。
- 每个模型以米为单位、Y 轴向上，原点设在建筑底面中心。导出后告知实际尺寸及是否含裙房，便于替换 `src/campus.ts` 中的占位模型。
