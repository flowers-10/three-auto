## 道路车辆（2026-10-19）

源文件为 Downloads 中的 `Meshy_AI_Golden_Horizon_SUV_1019083424_texture.glb` 和 `Meshy_AI_Midnight_Glide_1019090631_texture.glb`。使用 glTF Transform 4.5.1 进行顶点合并、Meshopt 压缩和 1024×1024 WebP 贴图压缩，不进行减面；两者保留 9,385 / 10,118 个三角面，文件由 6.52 / 5.61 MB 缩到 343 / 242 KB。原始车头均朝 -X，加载时统一到 +Z 前向并按车长适配，车轮底部贴在路面上。

当前有两辆 SUV 和一辆轿车，最多三辆同时出现。车辆通过两条纵向道路的南北入口进出，有四条直行路线和两条经过中间横路转弯的路线。各次行程从地图一端进入，在另一端驶出后隐藏，分别等待约 8–25 秒再从不同入口开始新行程。首轮出场时间为 0、4.8、12.6 秒，后续任意两次出场至少相隔 2.5 秒；入口被占用时继续等待。

三辆车基础速度分别为 5.8、7.1、8.6 米/秒（约 21、26、31 km/h），每次行程再随机浮动 ±10%，转弯会减速，同向接近前车时会跟随减速。路线按道路贴图中的轻微弯曲适配，车道距道路中心 3.3 米，车头跟随路径切线。车辆到达终点后不会立即跳回起点，后台长帧也会限制单次推进时间。

实现位于 `src/campus/traffic.ts`、`trafficRoutes.ts` 与 `trafficSimulation.ts`，车型只加载一次并共享网格和材质。左下角“查看车辆”进入跟车视角，“箭头视角 / 园区总览 / 查看双子塔”退出跟车。跟车入口为 `http://127.0.0.1:1231/?tab=campus&focus=traffic`。状态栏显示当前正在地图内行驶的车辆数量。

`scripts/check-campus-traffic.mjs` 检查六条穿行路线的入口/出口、4.9×2.15 米车身沿途仍在沥青路面内、不同出场时间和速度、消失后更换入口返回，以及五分钟模拟中持续错开的多次出场。使用 Node 24 运行 `node --experimental-strip-types --test packages/examples/scripts/check-campus-traffic.mjs`。同时通过 TypeScript、示例构建及浏览器行驶预览检查。

## Meshy 生成与交付约束

- 使用**单资产参考图**进入 Image-to-3D；不要把最初的整张鸟瞰效果图直接喂给 Meshy，否则它会把道路、树木和其它楼糊成一个巨型网格。
- 优先生成带 PBR 贴图的 GLB。检查背面、屋顶、底面、法线与窗格；前后左右都应可用。发现建筑像薄片时，先修改参考图的角度或增加侧视图，再重新生成。
- 图 A 目标 ≤ 120k 三角面、贴图 ≤ 2K；图 B ≤ 30k 三角面、贴图 ≤ 1K；图 C ≤ 10k 三角面。尽量一资产一材质、少量纹理，避免透明玻璃和细碎几何。
- 每个模型以米为单位、Y 轴向上，原点设在建筑底面中心。导出后告知实际尺寸及是否含裙房，便于替换 `src/campus.ts` 中的占位模型。
